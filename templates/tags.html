Tags find the little markers IPTV providers put in program titles, like the tiny ᴸᶦᵛᵉ and ᴺᵉʷ. In the TV Guide and in program searches, a tag highlights the programs that carry its marker and lets you filter on them. In a recording's file name, {tag:live} writes "live" when the program has that marker and nothing when it does not, and the file name settings can remove or replace the marker itself. ChannelBin starts with two, live and new, for the markers most providers use; edit or delete them like any other.
