Support bundle

ChannelBin makes every effort to redact every URL and pseudonymize all account, channel and group names before the zip is built (unless you opt-in to include the names). There are multiple layers of checks and tests to confirm that is all working as expected. However, you should still review the file before posting it anywhere in public. A recording name you typed, a program title, or a file path can still have identifiable information.
Sanitized diagnostic zip for troubleshooting - secrets replaced/masked throughout, never a copy of dvr.db or config.yaml. Account, channel and group names are replaced with pseudonyms (account 3, channel 1042) unless you choose to include them.
